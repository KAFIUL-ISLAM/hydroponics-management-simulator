# Changelog

## v1.0.0 Technical Assessment Edition

v1.0.0 is the completed technical-assessment release prepared for publication. The latest published release remains v0.7.0 until the final GitHub release is verified.

### Workshop and interface

- Refined hover, selection and keyboard-focus states.
- Preserved mouse-first drag-and-drop with live slot eligibility.
- Added clear blocker feedback and persistent machine status.
- Improved chamber, manual and analysis-tool focus restoration.
- Preserved inventory selection across modal tools.
- Updated manual spacing and bilingual tab presentation.
- Added Reduced Motion-compatible feedback.

### Cultivation and delivery

- Preserved the three-crop farming loop and legacy dashboard entry points.
- Added the optional Farming Manual and focused technical tools.
- Retained deterministic Kotton concentration experiments.
- Prepared a Windows standalone candidate with fixed resolution checks.
- Added sixteen procedural one-shot workshop effects.

### Verification

- The final source candidate reports 20/20 suites, 1,749 explicit checks and four original crop assertion groups.
- 461 workshop GUI checks and 72 audio checks are subsets of the final total.
- The runtime-only Windows PCK contains all 69 verified resource paths and excludes development content.
- The developer passed 29/29 standalone manual checks on the original build and 29/29 on the clean build.
- M11 historical verification covers 30 manual checks and 1,480 explicit automated checks.
- M10 historical verification covers 19 manual checks and 1,440 explicit automated checks.
