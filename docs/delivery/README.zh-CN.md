# 轨道水培实验室

**v1.0.0 · 技术评审版 · Windows x86-64**

本包提供一个受《深空当铺》水培农业系统启发的可玩技术原型。请将 `Game/Orbital Hydroponics.exe` 与同目录下的 `Orbital Hydroponics.pck` 保留在一起，然后运行 EXE。

![工作间初始画面](Screenshots/01-initial-workshop.png)

## 快速体验

1. 在库存中选择咖啡豆、营养果或韧棉种子，双击培养舱。
2. 将种子拖入槽位。机器在播种后自动运行。
3. 将纯水、能量、营养片或兼容模组拖入对应槽位。
4. 使用 **Next Night** 推进夜间结算。
5. 成熟后逐件点击产出进行领取；咖啡豆产物可再种植。
6. 使用右上角入口查看手册、种子档案、液体分析、设备、DNA 编辑器或音频设置。

## 界面与操作

- 支持 1280 × 720 和 1920 × 1080。
- 支持鼠标拖放、悬停说明和键盘导航。
- 按 **F1** 或右上角 **?** 打开种植手册。
- 按 **Escape** 关闭当前工具或培养舱。
