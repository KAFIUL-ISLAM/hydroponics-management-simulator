# Documentation in this package

- `HYDROPONICS_DESIGN_ANALYSIS_ZH.md` presents the gameplay, system design, numerical model and project limitations.
- `DEMONSTRATION_GUIDE.md` describes the normal workshop flow and focused technical demonstrations.
- `TESTING_REPORT.md` separates automated source regression from the original and clean Windows builds’ developer manual acceptance.
- `CREDITS_AND_LICENSES.md` records project direction, AI-assisted development, generated artwork, synthesized audio and third-party notices.

The package does not include project source. Repository implementation references are retained as path citations. The package screenshots and provenance are listed in `../SCREENSHOT_MANIFEST.md`.
