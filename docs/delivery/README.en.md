# Orbital Hydroponics

**v1.0.0 · Technical Assessment Edition · Windows x86-64**

This playable prototype is inspired by the hydroponics system in *Probably Stolen*. Keep `Game/Orbital Hydroponics.exe` beside `Orbital Hydroponics.pck` in the same folder, then launch the EXE.

![Initial workshop](Screenshots/01-initial-workshop.png)

## Try the workshop

1. Select a Coffee Beans, Nutrition Fruit or Kotton seed and double-click the chamber.
2. Drag the seed into its slot. The machine starts automatically after planting.
3. Drag water, energy, tablets or compatible modules into their slots.
4. Press **Next Night** to advance settlement.
5. Collect mature output individually. Coffee Beans output can be replanted.
6. Use the upper-right controls for the manual, Seed Analysis, Liquid Analysis, Equipment, DNA Editor or Audio Settings.

## Interface and controls

- Supports 1280 × 720 and 1920 × 1080.
- Supports mouse drag-and-drop, hover information and keyboard navigation.
- Press **F1** or the upper-right **?** button to open the Farming Manual.
- Press **Escape** to close the active tool or chamber.
