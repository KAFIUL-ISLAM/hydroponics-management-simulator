## How to read the matrix

- **Must**, **Should**, **Could**, and **Out** are GDD priorities. **Ref** marks reference or project-support detail with no separate GDD priority. A Must row can map to more than one GDD paragraph. The priority mapping below covers all nine Must categories.
- **V-M01** means the stated behavior has matching M01 acceptance evidence. **Partial** means an M01 capability exists but does not fulfill the complete requirement. **Missing** means the production behavior is absent. **Deferred** identifies a scoped option or explicit exclusion. Test columns specify future evidence unless the row cites the existing M01 gate.
- Formula IDs and source keys are defined in the [calculation contract](CALCULATION_CONTRACT.md). `GDD §n` refers to the English or corresponding Chinese section. Mxx and owner names specify expected implementation placement, not files already added. Cross-system references are prerequisites; a dash means no separate formula or prerequisite is needed.
- Current baseline evidence: [M01 final report](M01_FINAL_REPORT.md) · [Test runner](../tests/run-tests.ps1) · [Prototype crop fixture](../resources/lettuce_prototype.tres) · [GDD scope and acceptance](GDD.md#L692).

## Reference detail within the inventory

- **Equipment and locking (EQP-03/04/05).** The source distinguishes a powered battery, a grid service with its own fees, and an output-limited energy device. Old starter machines differ from the plain unit. A running plant locks its seed and modules while the vessel can be serviced between settlements. The ordinary machine's output grid is 9 × 6. The modifier table below is reference data, not a commitment to ship every module. [Equipment and modules](https://wiki.biligame.com/probablystolen/index.php?title=%E6%B0%B4%E5%9F%B9%E7%B3%BB%E7%BB%9F&oldid=11302)

| Module family | Reference effect relevant to scope | Requirements |
|---|---|---|
| Nutrition Fruit / Kotton weaving | Per-module fruit count bonus. Weaving swaps fiber for fabric without a separate count bonus and changes the machine's operating rates. | EQP-03, HRV-03 |
| Cap mushroom neutralization / nightmare | Alternative output conversions; neutralization has precedence when both are installed. Aggregate machine stats still apply. | EQP-03, GEN-05, OPT-01 |
| Filler grass / hydroponic reed | Filler bonus has a single special effect and suppresses seed return. Reed filter output increases with installed copies; purification belongs to the plant trait. | EQP-03, POL-03, GEN-04, OPT-01 |
| Hydroponic smuggling | Alters the mother's legality state on running nights. Consumer legality remains separate from component, growth and harvest calculations. Exclude the economy/legal subsystem under OOS-01. | EQP-03, OOS-01 |

These module effects and priority rules are grouped from the agriculture reference. [Specialized modules and failure behavior](https://wiki.biligame.com/probablystolen/index.php?title=%E6%B0%B4%E5%9F%B9%E5%86%9C%E4%B8%9A&oldid=11463)

- **Analysis and inventory (UI-02, UI-03, GEN-03, INV-01/02).** Plant, water, and genetic analysis are distinct information surfaces. The first dashboard can expose their relevant state without modeling the individual tools. Keep seed containers separate from slot-ready seeds, and keep stored solution reusable. The reference guide's distribution channels, NPCs, water trade, and processing examples are scope context.
