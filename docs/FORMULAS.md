## 3. 矿物质补充

### 3.1 营养片

每片水培营养片提供：

\[
M_{\text{tablet}}=15\text{ ml}
\]

### 3.2 矿物质浓度

矿物质浓度可以按下式计算：

\[
C=\frac{M}{W}\times100\%
\]

其中：

- \(C\)：矿物质浓度。
- \(M\)：矿物质体积。
- \(W\)：纯水体积。

注意：这里的分母是纯水量，不是混合液总体积。

例如：

- 纯水：1000 ml。
- 矿物质：15 ml。

\[
C=\frac{15}{1000}\times100\%=1.5\%
\]

状态：已核对。

## 4. 作物矿物质消耗

每点生长进度对应的矿物质吸收量：

| 作物 | 每点生长进度消耗矿物质 |
| --- | ---: |
| 营养果 | 0.050 ml |
| 韧棉 | 0.075 ml |
| 咖啡豆 | 0.030 ml |

矿物质吸收计算：

\[
M_{\text{absorption}}=G\times R
\]

其中：

- \(G\)：实际推进的生长进度点数。
- \(R\)：作物每点生长进度的矿物质消耗量。

例如，假设营养果推进10点生长进度：

\[
M=10\times0.050=0.5\text{ ml}
\]

注意：以上只表示作物生长吸收的矿物质，不包含混合液消耗带走的矿物质。

状态：已核对。

## 5. 矿物质失衡造成的健康损伤

隐藏健康值初始为：

\[
H_0=10000
\]

生长评分：

\[
S=\frac{H}{100}
\]

其中 \(H\) 为隐藏健康值，\(S\) 为百分比形式的生长评分。

每点生长进度的矿物质损伤：

| 矿物质条件 | 每点生长进度健康损失 |
| --- | ---: |
| 在最佳范围内 | 0 |
| 高于最佳范围 | 50 |
| 低于最佳范围 | 100 |

对应生长评分变化：

- 高于最佳范围：每点降低0.5个百分点。
- 低于最佳范围：每点降低1个百分点。

例如，假设作物在矿物质不足时推进10点：

\[
\Delta H=10\times100=1000
\]

\[
H_{\text{new}}=10000-1000=9000
\]

\[
S=90\%
\]

状态：已核对。

## 6. 污染损伤

Wiki 将污染损伤分成三个计算阶段。

### 6.1 污染物浓度值

\[
C_p=\frac{V_p\times10000}{V_w}
\]

其中：

- \(C_p\)：污染物浓度值。
- \(V_p\)：污染物体积，单位 µL。
- \(V_w\)：水体积，单位 µL。

### 6.2 损害档位

先计算：

\[
D=C_p\times S_p
\]

其中：

- \(D\)：污染损害档位计算值。
- \(S_p\)：植物污染敏感度。

初始污染敏感度为100%，遗传特性可以改变敏感度。

根据结果查找损害表：

| 损害档位 | 健康值损失 |
| --- | ---: |
| 0–10 | 0 |
| 11–15 | 15 |
| 16–20 | 20 |
| 21–25 | 30 |
| 26–30 | 40 |
| 31–40 | 60 |
| 41–60 | 80 |
| 61–100 | 160 |
| 101–200 | 320 |
| 高于200 | 640 |

### 6.3 实际污染损伤

\[
\Delta H_p=L\times R_p
\]

其中：

- \(L\)：损害档位对应的健康值损失。
- \(R_p\)：作物对应污染物抗性。

不同污染物的损伤需要分别计算并累加。

### 6.4 作物污染抗性

| 作物 | 污染物抗性 |
| --- | ---: |
| 营养果 | 1.00 |
| 韧棉 | 1.26 |
| 咖啡豆 | 1.01 |

状态：已核对。

注意：污染敏感度与污染物抗性是两个不同的属性，不能混为一谈。

## 7. 液体消耗与矿物质流失

Wiki 说明，每晚消耗液体时，水和矿物质会按照它们在混合液中的比例分配损失。

因此：

\[
M_{\text{total loss}}
=

M_{\text{absorption}}
+
M_{\text{liquid loss}}
\]

这意味着不能只使用作物吸收量来代表矿物质总消耗。

Wiki 还说明了微升级别的分配和舍入规则。具体实现需要在开发阶段进一步验证。

状态：基本机制已核对；完整分配算法待实现前详细核对。

## 8. 收获与健康度

健康值会影响不同作物的收获表现。

例如：

- 韧棉：健康度会影响收获数量和纤维大小。
- 咖啡豆：健康度会影响收获数量。
- 营养果：健康度主要影响果实大小，不影响基础数量。

韧棉和梦帽菇的健康度收获区间在 Wiki 中有详细表格，后续实现时需要单独整理。

状态：基础规则已核对；完整收获算法待进一步整理。

## 9. 本项目原型的计算原则

1. 所有资源使用统一单位。
2. 所有计算逻辑与 UI 分离。
3. 核心计算尽量使用独立函数。
4. 每个公式都应有对应测试案例。
5. 舍入规则必须明确。
6. 不确定的数值不能直接作为最终参数。
7. 参考游戏公式与原型简化公式必须明确区分。
